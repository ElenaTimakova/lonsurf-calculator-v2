# Калькулятор дозы Лонсурф®

Самостоятельный встраиваемый блок-калькулятор для лендинга препарата
**Лонсурф®** (трифлуридин + типирацил, Servier) для специалистов
здравоохранения. Считает стартовую дозу, разбивку приёмов утром/вечером,
количество таблеток 15 / 20 мг и необходимое число упаковок на курс.

Дизайн-токены (цвета, типографика, скругления, тени, фирменный
«закатный» градиент) унаследованы от десктоп-лендинга Лонсурф® и собраны
в одном CSS-файле как переменные.

> ⚠️ **Расчёт справочный и не заменяет клиническое решение.**
> Финальное назначение определяется лечащим врачом.
> Материал предназначен для специалистов здравоохранения.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `index.html` | Демо-страница: один экземпляр калькулятора, открывается в браузере без сборки. |
| `Calculator.css` | Все стили компонента (БЭМ-классы `lc-*` и CSS-переменные). |
| `Calculator.js` | Vanilla-JS рендерер для `index.html`. Не нужен в production. |
| `Calculator.jsx` | React-компонент `<DoseCalculator />` для встраивания в лендинг. |
| `pattern.svg` | Декоративный паттерн в шапке блока. |

## Быстрый запуск

```bash
cd lonsurf-calculator
python3 -m http.server 5173
# открыть http://localhost:5173
```

Никакого `npm install` — это статика на ванильных HTML/CSS/JS.

## Состояния и UX

1. **Начальное** — поля пусты, плейсхолдеры «Например, 70 / 180 / 28»,
   справа — белая плашка с иконкой и подсказкой «Введите параметры
   пациента…». Кнопка «Рассчитать дозу» всегда активна.
2. **Заполнение** — фокус-обводка `#FFBB54` с halo. Звёздочка `*` рядом
   с лейблом обозначает обязательное поле.
3. **Ошибка валидации:**
   - на blur пустого поля или при клике «Рассчитать» с пустым полем —
     красная обводка `#C80D46` + текст **«Поле обязательно для заполнения»**;
   - при вводе не-числа — **«Введите число, например, 80»**;
   - при вводе веса > 150 — **«Вес должен быть не более 150 кг»**.
4. **Успешный расчёт** — справа три блока в одной белой карточке:
   *Расчёт дозы*, *Количество таблеток*, *Количество упаковок*.
   Карточки внутри блоков — на сером `#F7F7F7`. На мобильной версии
   страница плавно проматывается на пол-экрана вниз, чтобы пользователь
   сразу увидел результат.
5. **Невозможность расчёта** — клиническая комбинация выходит за
   допустимые пределы (например, суточная доза > лимита для тяжёлой
   почечной недостаточности): карточка с пояснением и CTA «Изменить
   параметры».

## Адаптив

- **Desktop:** 2 колонки 1 / 2 (форма / результат). 5 карточек «Расчёта
  дозы» в одну строку, 4 карточки таблеток и 4 — упаковок.
- **Tablet (≤ 1024 px):** одна колонка, форма сверху, результат снизу.
- **Mobile (≤ 768 px, 375 px):** карточка «Площадь поверхности тела»
  растягивается на 100 % ширины, остальные — по две в ряд. Пустой
  блок-плейсхолдер скрыт. Декоративный паттерн убран.

## Встраивание в React-лендинг

```tsx
import DoseCalculator from './lonsurf-calculator/Calculator.jsx';
import './lonsurf-calculator/Calculator.css';

// в любом месте лендинга:
<DoseCalculator />
```

Компонент самодостаточен: не делает сетевых запросов, не требует
контекста, всё хранит в локальном стейте.

## Что НЕ реализовано (и не должно быть на этом этапе)

- **Финальные клинические формулы.** Функция `compute()` внутри
  `Calculator.js` / `Calculator.jsx` — это иллюстрация
  (площадь тела по Дюбуа + перенастраиваемые `perM2` / `maxDaily`
  по почечной функции). Перед production нужно заменить
  на согласованные с медицинским отделом формулы и валидировать.
- Бэк, админка, пользовательские настройки.
- A11y-доводка (фокус-trap, `aria-live` на результате) сверх базовых
  `aria-labelledby` / `aria-label`.
- Печать / экспорт результата в PDF.
